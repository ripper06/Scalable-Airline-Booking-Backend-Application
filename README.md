# ✈️ Airline Booking System (Microservices Architecture)

This project is a production-grade **Airline Booking System** built using a **microservices architecture** to ensure scalability, modularity, and fault tolerance.  
It includes independent services for booking, flight management, notifications, and API gateway routing.

---

## 🧱 Microservices Repositories

| Service | Description | Repository Link |
|----------|--------------|-----------------|
| 🧭 **API Gateway** | Central gateway managing all routes and authentication. | [API-Gateway-Airline-Application](https://github.com/ripper06/API-Gateway-Airline-Application) |
| 🛫 **Flight Booking Service** | Handles flight creation, seat allocation, and booking logic. | [Flight-Booking-Service](https://github.com/ripper06/Flight-Booking-Service) |
| 💳 **Backend Core Service** | Core backend for data management and system orchestration. | [Backend-Flight-Booking-Application](https://github.com/ripper06/Backend-Flight-Booking-Application) |
| 📩 **Notification Service** | Manages email notifications using RabbitMQ and microservice queues. | [Airline-Notification-Service](https://github.com/ripper06/Airline-Notification-Service) |

---

## ⚙️ Tech Stack
- **Backend:** Node.js, Express.js, MySQL  
- **Message Queue:** RabbitMQ  
- **Deployment:** Docker, AWS  
- **CI/CD:** GitHub Actions  
- **Authentication:** JWT, Role-Based Access Control (RBAC)  

---

## 🚀 Features
- Real-time flight search and seat booking  
- Overbooking prevention and transactional safety  
- Microservice communication using RabbitMQ  
- Automated email notifications  
- Fully containerized with Docker  
- CI/CD integration with GitHub Actions
